# CodSoft Java Development Internship

## About This Repository

This repository contains my Java programming tasks completed as part of the CodSoft Java Development Internship. These projects help me practice Java fundamentals, problem-solving, conditional statements, loops, arrays, and event-driven programming.

## Projects

### 1. Number Guessing Game
**File:** `NumberGame.java`

A Java game in which the computer generates a random number between 1 and 100, and the user tries to guess it.

**Features:**
- Random number generation
- Hints for guesses that are too high or too low
- Limited attempts
- Multiple rounds
- Score calculation

### 2. Quiz Application with Timer
**File:** `QuizApp.java`

A Java Swing application that presents multiple-choice questions and calculates the user's score.

**Features:**
- Multiple-choice questions
- Four answer options per question
- Countdown timer for each question
- Automatic progression when time runs out
- Final score display

### 3. Student Grade Calculator
**File:** `StudentGradeCalculator.java`

A Java program that calculates a student's total marks, average percentage, grade, and result based on marks entered for each subject.

**Features:**
- Input marks for multiple subjects
- Validation of marks from 0 to 100
- Total marks calculation
- Average percentage calculation
- Grade and pass/fail result

## Technologies Used

- Java Development Kit (JDK) installed

## How to Run

### Number Guessing Game

```bash
javac NumberGame.java
java NumberGame
```

### Student Grade Calculator

```bash
javac StudentGradeCalculator.java
java StudentGradeCalculator
```

### Quiz Application with Timer

```bash
javac QuizApp.java
java QuizApp
```

The Quiz Application requires a Java environment that supports graphical user interfaces.
