
# CodSoft Java Development Internship

This repository contains my Java Development Internship tasks.

## Task 1: Number Guessing Game
- Generates a random number.
- Gives hints to the user.
- Supports multiple rounds and scoring.

## Task 2: Student Grade Calculator
- Accepts marks for multiple subjects.
- Calculates total and average percentage.
- Displays grade and result.

## Task 3: ATM Interface
- Checks account balance.
- Deposits and withdraws money.
- Validates transactions using Java OOP.

## Technologies
- Java
- Object-Oriented Programming
- Scanner
- Arrays and loops

## How to Run
1. Install the Java JDK.
2. Open a terminal in the task folder.
3. Compile the Java file using javac.
4. Run the program using java.
